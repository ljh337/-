# 棋牌隧道联机

统一启动器集成斗地主与湖南麻将。手机浏览器打开 Cloudflare Tunnel 地址进入游戏大厅；电脑管理端可以在创建每个房间时单独选择游戏，并查看两种游戏的实时牌桌状态。

## 启动接收端

在此目录双击 `启动接收端.bat`，或打开 PowerShell 运行：

```powershell
python web_server.py
```

默认监听 `0.0.0.0:8876`。启动窗口会显示管理口令、管理页面地址、CSV 文件位置和 Cloudflare Tunnel 命令。请保持此窗口运行。

保持接收端运行，然后双击 `启动Cloudflare隧道.bat`，或在另一个 PowerShell 窗口启动 Cloudflare Quick Tunnel：

```powershell
cloudflared tunnel --url http://127.0.0.1:8876
```

`cloudflared` 输出的 `https://...trycloudflare.com` 地址就是手机访问地址。电脑统一管理台使用 `http://127.0.0.1:8876/admin`；管理口令在接收端启动窗口中。也可以通过隧道地址加 `/admin` 打开管理台。不要把管理口令发给玩家。

## 开局与加入

1. 在电脑管理台输入启动窗口显示的管理口令。同一时间只允许一台设备登录管理端；其他设备会提示当前已有设备在线。
2. 当前设备结束管理时，点击“下线”；下线后其他设备即可使用管理口令登录。直接关闭页面或设备不会自动释放登录，需要从已登录设备点击“下线”。
3. 在同一管理台创建房间时选择“斗地主”或“湖南麻将”，然后设置真人数量。斗地主为 1–3 位真人；湖南麻将为 1–4 位真人。剩余座位自动安排 AI，设置只影响新创建的房间。
4. 把管理台生成的游戏专属邀请链接发给玩家。玩家也可以打开隧道首页，在同一个房间号输入框输入房间号；接收端会自动识别游戏并打开对应客户端。
5. 真人玩家输入昵称加入并准备；昵称最多 8 个字符，不能使用与电脑玩家或系统相似的名称。斗地主真人都准备后自动发牌并轮流叫地主。有人叫地主后，其他玩家可以选择抢地主或不抢；第一位抢地主者会立即成为地主并开始出牌，三张底牌会向全桌公开 3 秒。若其他两人都不抢，则由最初叫地主者成为地主，同样公开底牌 3 秒；整轮无人叫地主则自动重新发牌。AI 会自动参与叫/抢地主和出牌。麻将真人准备后由 AI 补足座位。

两种游戏可以混合创建多桌并在同一管理台监督。电脑玩家每次行动前会等待 1.6 秒，与玩家端桌面中央操作提示的显示时长同步；确定地主后会先完整展示三张底牌 3 秒，再允许电脑玩家继续行动。斗地主玩家手机端支持按牌面大小排序的手牌、叫地主、抢地主、不叫、不抢、出牌和不出；页面在刷新或短暂断线后会尝试恢复原玩家身份。管理台显示每个房间的打开时间和已使用时长；关闭后显示关闭时间并固定最终时长。牌局卡片上的“关闭房间”会结束对应游戏的房间并记录管理操作，历史牌局和操作记录保留在各自 CSV。点击牌局卡片可查看该游戏的当前进度和操作记录。

牌局结束后，每位真人玩家可以选择是否再开一局。所有真人玩家都确认后，系统会在原房间沿用原座位和玩家身份重新发牌；玩家可在新一局开始前取消自己的确认。

点击管理台中的“查看 CSV 记录”可打开 CSV 查看器，按房间或关键词筛选、分页查看操作和当时的牌局快照（包括玩家手牌）。选择一个房间后，可点击“一键导出本局数据（Excel CSV）”下载完整单局记录：包括全部操作、操作说明、牌局状态及各座位在每个操作时刻的手牌。导出文件为 UTF-8 BOM 编码的 CSV，可使用 Excel、WPS Office、LibreOffice 等打开。该查看器需要管理口令授权；为避免泄露，页面不会显示 CSV 快照中的玩家重连凭据。

CSV 查看器可按房间筛选并查看整局记录；可删除单条操作记录，也可多选并批量删除多个已关闭房间的全部 CSV 数据。进行中的房间不能被选择或删除；批量删除会先验证所有房间，任何房间未关闭时整批取消。删除会改写 CSV 且无法撤销；删除某房间最新的单条记录时会将该位置替换为隐藏的恢复检查点，确保重启接收端后房间状态不回退。

## 记录与隐私

所有牌局写入本目录唯一的数据文件 `landlord_games.csv`。CSV 使用带 BOM 的 UTF-16 编码，适配 Excel 双击打开；接收端会自动迁移 UTF-8 或 UTF-16BE 的旧文件，并保留已有记录。CSV 每行包含局号、时间、操作人、操作类型、操作详情和操作后的状态快照；牌局状态可在接收端重启后恢复。快照中含各玩家手牌及重连凭据，因此 CSV 只应留在接收端，不要公开分享。

## 验证

```powershell
python -m unittest -v test_server.py
```

只使用 Python 标准库，不需要额外安装 Python 包。Cloudflare Tunnel 需要已安装并可运行 `cloudflared`。
